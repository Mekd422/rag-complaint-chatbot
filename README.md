# Intelligent Complaint Analysis for Financial Services

This project implements a Retrieval-Augmented Generation (RAG) chatbot to analyze customer complaints from the CFPB dataset and provide actionable insights for internal stakeholders.

## Objectives
- Semantic search over customer complaints
- Evidence-backed AI-generated insights
- Multi-product complaint analysis

## Tech Stack
- Python
- FAISS / ChromaDB
- Sentence Transformers
- LLMs (via RAG)
- Gradio / Streamlit
